# REVIEW.md — Саморевью по чек-листу (слайды 29–32)

Ниже приведена自我оценка решения по критериям рубрикатора.

## 1. REST: ресурсы, методы, коды

| Требование | Статус | Комментарий |
|---|---|---|
| CRUD для Books | ✅ Сделано полностью | GET/POST/PUT/DELETE на `/books` и `/books/{id}` |
| CRUD для Readers | ✅ Сделано полностью | GET/POST/PUT/DELETE на `/readers` и `/readers/{id}` |
| Loans: создание, список, получение по id | ✅ Сделано полностью | POST `/loans`, GET `/loans`, GET `/loans/{id}` |
| Возврат через POST /loans/{id}/return | ✅ Сделано полностью | Реализован как отдельная операция, не DELETE |
| `/v1/` в servers | ✅ Сделано полностью | Оба сервера (продакшен и локальный) начинаются с `/v1` |
| kebab-case в URL | ✅ Сделано полностью | Все пути в kebab-case |
| Осмысленные коды (201/404/409/422 и т.д.) | ✅ Сделано полностью | Используются 200, 201, 204, 400, 404, 409, 422, 500 |

## 2. Схемы запросов/ответов

| Требование | Статус | Комментарий |
|---|---|---|
| Схемы Book, Reader, Loan | ✅ Сделано полностью | Описаны через `components/schemas` |
| request/response схемы | ✅ Сделано полностью | Отдельные схемы для Create/Update и ответов |
| `available_copies` только в response | ✅ Сделано полностью | Поле помечено `readOnly: true`, отсутствует в запросах |
| Вычисляется из `total_copies` и выдач | ✅ Отражено в описании | Зафиксировано в `info.description` и бизнес-правиле №7 |
| Неизвестные поля запрещены | ✅ Сделано полностью | `additionalProperties: false` во всех схемах |

## 4. Идемпотентность и бизнес-правила

| Требование | Статус | Комментарий |
|---|---|---|
| Idempotency-Key на POST /loans | ✅ Сделано полностью | Параметр заголовка в операции `createLoan` |
| Полный replay ответа | ✅ Описано | В `description` операции и в STYLE.md правило №8 |

| Конкурентные повторы | ✅ Описано | В `description` операции |
| TTL 24 часа | ✅ Описано | В `description` операции и STYLE.md правило №8 |

| Правило возврата POST, не DELETE | ✅ Отражено | Бизнес-правило №3 |
| Просроченные через ?status=overdue | ✅ Отражено | Бизнес-правило №4 |
| Запрет удаления с активными выдачами | ✅ Отражено | Бизнес-правило №5, коды 409 на DELETE |
